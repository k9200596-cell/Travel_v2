- 헤더 우측 v50 표기
- 일정표 인쇄/PDF '경비 포함' 체크박스 추가 (기본 미체크)
- 체크 시에만 경비를 모든 일정과 준비·메모 뒤 마지막에 출력
- 체크하지 않으면 인쇄용 비용 열과 경비 섹션 제외
- 기존 24개 도시, 240개 명소, 갤러리, 일정 저장, 환율, Booking.com 연결 코드 유지

- 기존 사진 메타데이터는 재검증하지 않았습니다.
