# K-TRAVEL PICKS v48 — 수동 배포용

기준: GitHub main은 v46, 직전 미배포 로컬 산출물 v47을 바탕으로 v48 제작.

## 새 기능
- 여행지별 최신 제공 환율 조회: Frankfurter v2 (무료, 키 없음), 기준일·출처·조회시각 표시
- 환율 직접 수정, 새로고침, 오프라인 캐시(실패 시 마지막 성공 환율)
- 항공료는 원화 기본값, 다른 항목은 원화/현지 통화 선택 후 자동 환산
- 일정 PDF 인쇄: 경비 8개 항목, 환율 정보, 총액·1인당, 일자별 일정 포함

## 수동 적용
1. `index.html` 단일 파일을 로컬 브라우저에서 열어 날짜·경비·환율·PDF 인쇄를 테스트합니다.
2. https://github.com/k9200596-cell/Travel_v2 의 main 브랜치 index.html을 교체합니다.
3. GitHub Pages (Deploy from a branch, main/root) 배포 상태와 공개 화면 v48을 확인합니다.

## 주의
- 자동 배포는 수행하지 않았습니다. GitHub main은 v46입니다.
- 실 브라우저 실행은 관리정책에 의해 차단되어 UI·인쇄·CORS E2E 검증이 필요합니다.
- 관광명소 240곳 중 사진 미확보 155곳은 기존 대체 이미지 유지(무단 이미지 추가 없음).
- 외부 환율은 실제 결제환율과 다를 수 있습니다. 데이터 출처 https://frankfurter.dev/
- 부킹닷컴은 외부 사이트에서 조건 재확인 필요.
